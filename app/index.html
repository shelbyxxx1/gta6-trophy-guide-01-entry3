Roadmap to the platinum

Eight stages, in the order the official descriptions suggest: story first, named missions inside it, side stories next, then the great Leonida tour, the activity bench, and the 100% push last. Every one of the 55 trophies appears in exactly one stage.

Missable watchlist

Built from the official descriptions, not from rumour: a trophy is flagged here when its description names a condition that can fail in the moment it is attempted — undetected, a single use, back-to-back, a second try, a choice. Story trophies are not flagged, because their descriptions ask only that you complete a mission or a chapter. For each flagged trophy, the guide states the condition and the save to make before you attempt it.

Sources & method

How to read a guide entry

Every trophy card shows the official name, description and grade exactly as PlayStation publishes them, then a guide written for this entry in our own words — what to do, where and how, and when it can be missed — and a source line naming where its facts come from. A cited guide beats an uncited one: if a detail is not in the official description or the kit lines, the guide says so instead of inventing it.

The Leonida Fieldbook is an original, unofficial companion. It uses no Rockstar Games logo, artwork or screenshots; the look is its own. Trophy names and descriptions are reproduced from the official PlayStation list. Works fully offline — every file it loads lives under app/.
